# RaçaPet - Aplicativo de Reprodução Canina 🐾

O **RaçaPet** é uma proposta de aplicação móvel concebida para auxiliar tutores a encontrar parceiros reprodutivos para seus cães de forma segura e responsável, condicionando o agendamento do cruzamento à validação prévia de exames por médicos veterinários habilitados e garantindo a proteção dos dados pessoais dos usuários.

Este repositório contém o código-fonte do protótipo de *front-end*, o instalador executável (`.apk`) e o modelo de dados desenvolvidos no âmbito do curso de Análise e Desenvolvimento de Sistemas do IFMT Campus Rondonópolis para submissão ao **VII CEPEx**.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (Android Nativo)
- **IDE:** Android Studio
- **Design de Interface:** Material Design & Braindraw
- **Modelagem de Dados:** MySQL Workbench (Diagrama ER)
- **Metodologia de Análise:** Análise Temática (Braun & Clarke, 2006)

---

## 📱 Módulos e Telas Implementados

1. **Autenticação e Cadastro (RF01):** Telas de login e cadastro inicial de tutores.
2. **Feed Inicial (RF06):** Apresentação de publicações e interação da comunidade.
3. **Busca de Parceiros (RF05):** Filtragem de cães aptos para reprodução.
4. **Meus Cães (RF02 a RF04):** Gestão do perfil do animal, vacinas e declaração de intenção sobre filhotes.
5. **Chat com Mensagens Pré-definidas (RF07):** Mecanismo de comunicação por lista de permissões para proteção da privacidade (LGPD).
